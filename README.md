# O230815_Car_resale — Used Car Valuation & Price Regression

A clean Python and Streamlit data science project that cleans used-car specifications with Pandas and Regex, analyzes how vehicle age and odometer mileage impact resale prices via regression, and estimates resale values with confidence charts.

## Project Structure

```text
O230815_Car_resale/
├── data/            # Dataset download links, schema notes, and local CSV files (gitignored)
├── notebooks/       # Jupyter notebooks for EDA, feature engineering, and modeling
├── src/             # Python modules for cleaning, modeling, and Streamlit dashboard
├── docs/            # Project documentation PDF
├── .gitignore
├── requirements.txt
└── README.md
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

See `data/README.md` for dataset links and schemas.
